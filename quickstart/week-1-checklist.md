# Week 1 Checklist — Bootstrap Your SDD Workflow

> Everything you should do in the first week to move from "installed the kit" to "actively using SDD."
> Estimated time: **5–8 hours across the week**.

---

## Day 1 (after Day 0 checklist)

- [ ] **Populate `pending-items-tracker.md`** with the 5 most important open items from your head, email, and Slack.
- [ ] **Run Monday Kickoff** using `prompts/monday-kickoff.md`. Save output.
- [ ] **Refine root `AGENTS.md`** with 2–3 project-specific conventions discovered in Day 0 test chats.

## Day 2

- [ ] **Write your first PRD** using `prompts/01-prd-from-transcripts.md`. Pick one small feature from your backlog.
- [ ] **Author your first per-capability `AGENTS.md`** using `templates/AGENTS.module.md`.
- [ ] **Test `epic-implementation-planner`** by sharing a real epic with the AI.

## Day 3

- [ ] **Draft your first Technical Solution Design** using `prompts/03-technical-solution.md`.
- [ ] **Have a peer tech lead review it.** Iterate 1–2 rounds.
- [ ] **Test `pr-readiness-check`** on any open PR you have.

## Day 4

- [ ] **Draft your first UI Component Strategy** (if this is a UI feature) using `prompts/04-ui-strategy.md`.
- [ ] **Draft your Implementation Phases** using `prompts/05-implementation-phases.md`.
- [ ] **Sign-off gate**: verify all four SuperSpec docs (PRD, Tech Solution, UI Strategy, Phases) are ready for phase 1 kickoff. See `docs/01-sdd-playbook.md` §15 for the checklist.

## Day 5 (Friday)

- [ ] **Run Friday Wrap** using `prompts/friday-wrap.md`. Save output.
- [ ] **Retro on the week**: which rules fired? Which never did? Which felt heavyweight?
- [ ] **Adjust the kit**: drop rules you didn't need; author 1–2 stack-specific rules you did need.

---

## Deliverables by end of week

- [ ] Root + at least one nested `AGENTS.md`
- [ ] `pending-items-tracker.md` populated
- [ ] `.cursor/rules/` and `.cursor/skills/` copied and adapted
- [ ] One PRD drafted
- [ ] One Technical Solution Design drafted
- [ ] One Implementation Phases plan drafted
- [ ] Monday kickoff + Friday wrap habit started

---

## Anti-patterns for week 1

| Anti-pattern | Fix |
|---|---|
| Copying the kit verbatim, no customization | Every project is different; adapt |
| Skipping the AGENTS.md refinement | Do it — this is where the biggest ROI hides |
| Not running the rituals | The rituals are the discipline; do them |
| Skipping the retro on Friday | Retro is the improvement mechanism |
| Trying to install all 21 rules and all 10 skills at once | Start with 5 rules + 3 skills; add as you hit real friction |

---

## Success criteria

By end of week 1, you should be at **Level 3** of the maturity model:

> AI IDE with rules + skills — Behavioral standards encoded once; rituals adopted. 1.7–2.2× throughput.

To reach **Level 4** (full 5-layer pattern, cross-team IP being shared), work through your first milestone using `quickstart/first-milestone-checklist.md`.
